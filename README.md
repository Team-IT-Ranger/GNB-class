# Gemini × Gemini Notebook — Class Workspace

ห้องเรียนออนไลน์แบบไฟล์สถิต (ไม่ต้อง build) สำหรับคลาส 3 ชั่วโมง (โครงหลักสูตรตามที่ Gemini ออกแบบ: Part 1 แนวคิดและเตรียมข้อมูล · Part 2 Notebook Deep Dive · Part 3 Workshop · ประเมินและเกียรติบัตร) "Gemini × Gemini Notebook (เดิมชื่อ NotebookLM)" กรณีศึกษาบริษัท ไร้ควันพันล้าน (สมมติ) โครงและส่วนที่ใช้ซ้ำ (Whiteboard, โน้ต, แชต, sidebar, ตรวจการบ้านตัวเลข) มาจากต้นแบบ Excel Class Workspace (`AppSpace/CLASS/CLAZZ`)

## มีอะไรในแอป

- **หน้าสรุปภาพรวม (Agenda):** จุดประสงค์การเรียนรู้ LO1-LO6, ไทม์ไลน์ 180 นาที (แกนหลัก + ส่วนเสริม), สิ่งที่ต้องเตรียม (แอดมิน/ผู้สอน/ผู้เรียน), ข้อจำกัดของเครื่องมือ
- **คู่มือผู้เรียน 6 บท** (Part 1: บท 01-04, Part 2: บท 05-06) พร้อมดาวน์โหลด PDF
- **สไลด์ 37 แผ่น** (ดึงจาก pptx) แผ่นที่ข้ามได้ติดป้ายไว้
- **แบบฝึกหัด Lab 0-5** (0 เตรียมพร้อม · 1 Protect ปิดชื่อ · 2 Master Prompt · 3 Gem · 4 Notebook · 5 ข้อขัดแย้งและ Studio) คัดลอก Prompt ได้ ตรวจการบ้านด้วยตัวเลขจริงจากชุดเอกสารสมมติ มีแผนสำรอง (Plan B) ทุก Lab
- **Part 3 Workshop** 3 สายงาน (ขาย & การตลาด / บัญชี & การเงิน / HR & แอดมิน) แยกเป็น 6 แผนก + นำเสนอกลุ่ม 15 นาที + Practical Check 6 ข้อ
- **คลังคำสั่ง (Prompt)** การ์ด 6 แผนก + คำสั่งตั้งต้นของ Gem
- **แบบทดสอบ:** ก่อนเรียน 12 ข้อ / Post-test ในคลาส 5 ข้อ (ไม่มีเกณฑ์ผ่าน มีตัวเลือก "ยังไม่ทราบ"), ความมั่นใจ 10 ข้อ, ติดตาม 7 วัน
- **เกียรติบัตรเข้าร่วมอบรม** (PDF ที่ผู้เรียนสร้างเองในเบราว์เซอร์ ปลดล็อกเมื่อทำ Post-test และแบบประเมินหลังเรียน ตั้งชื่อหน่วยงาน/ผู้ลงนามใน `config.js`)
- **ส่งลิงก์ผลงาน** (Notebook / Gem) แทนการอัปโหลดไฟล์
- **ไฟล์ฝึกปฏิบัติ** ชุดเอกสารสมมติ 12 ไฟล์ (รายไฟล์และ zip)
- Whiteboard, โน้ต, แชต, ธีมมืด, โหมดหนาแน่น, ค้นหา, QR ลิงก์แอป
- **โหมดผู้สอน:** ผลคะแนนผู้เรียน, เฉลยกับดัก, โน้ตผู้สอนในสไลด์, บันทึกการตรวจสอบและจุดที่ปรับจากแผน

## รันบนเครื่อง

```bash
python -m http.server 8765
```

แล้วเปิด http://localhost:8765 (ต้องเปิดผ่านเซิร์ฟเวอร์ ไม่ใช่ดับเบิลคลิก `index.html` เพราะฟอนต์และ clipboard ทำงานบน `file://` ไม่ครบ)

## ตั้งค่า

แก้ [`config.js`](config.js): `GAS_ENDPOINT` และ `GAS_SECRET` (ดู [`../backend/README.md`](../backend/README.md)), `INSTRUCTOR_URL_FLAG` และข้อมูลเกียรติบัตร (`CERT_ORG`, `CERT_ISSUER`, `CERT_COURSE`) เว้น `GAS_ENDPOINT` ว่างไว้ = ทุกอย่างอยู่ในเบราว์เซอร์ผู้เรียนเท่านั้น

## โหมดผู้สอน และไฟล์ที่ห้ามขึ้นสาธารณะ

- เปิดโหมดผู้สอนบนเครื่องคุณ: เข้าเว็บด้วย `?instructor=<INSTRUCTOR_URL_FLAG>` (ปิดด้วย `?instructor=off`) เป็นเพียงสวิตช์แสดงเมนู ไม่ใช่การล็อกอิน
- **`instructor-data.js`** เก็บโน้ตผู้สอนและเฉลยกับดัก อยู่ใน `.gitignore` และไม่ขึ้น GitHub Pages ผู้เรียนจึงเห็นไม่ได้ ผู้สอนเห็นเมื่อเปิดแอปจากโฟลเดอร์ของตัวเอง (สร้างใหม่ด้วย `materials/build-scripts/extract_slides.py`)
- **ข้อควรรู้:** ตารางเกณฑ์ตรวจการบ้านในแต่ละ Lab แสดงค่าอ้างอิงตามธรรมชาติของการตรวจตัวเลข (เช่น ส่วนลด 12% กับ 15%) จึงเป็นสิ่งที่ผู้เรียนเห็นได้ กับดักที่ต้องหาเอง (เหตุผลของความขัดแย้ง วิธีจัดการ) อยู่ในไฟล์ผู้สอนเท่านั้น

## ความเป็นส่วนตัว (ข้อ 10 ของ Methodology)

- ทุกอย่างบันทึกในเบราว์เซอร์ผู้เรียนก่อนเสมอ (`localStorage`)
- ส่งไปให้ผู้สอน **เมื่อผู้เรียนกดปุ่มส่งเท่านั้น** ทุกฟอร์มมีข้อความแจ้งว่าเก็บอะไร ไม่มีการส่งอัตโนมัติ ไม่มีการอัปโหลดไฟล์
- ชื่อที่ผู้เรียนกรอกเป็นข้อความอิสระ (ชื่อ-นามสกุล หรือชื่อเล่น + แผนก) ไม่มีการยืนยันตัวตน
- ข้อความแชตเห็นได้โดยทุกคนในคลาส หน้าจอเตือนให้ไม่พิมพ์ชื่อบุคคลอื่นหรือข้อมูลลูกค้า

## เผยแพร่ผ่าน GitHub Pages

1. push โฟลเดอร์นี้ขึ้น repository (ไฟล์ `.github/workflows/deploy-pages.yml` ใช้ deploy ให้เมื่อ push เข้า `main`)
2. Settings → Pages → Source: **GitHub Actions**
3. ตรวจว่า `instructor-data.js` ไม่ถูก commit (`git status` ต้องไม่เห็นไฟล์นี้)

## ทดสอบแล้วอย่างไร

- เปิดในเบราว์เซอร์: เรนเดอร์ครบ 38 เส้นทาง ไม่มี error ในคอนโซล ไทม์ไลน์รวม 180 นาที และลิงก์สไลด์ของทุกช่วงมีอยู่จริง
- เกียรติบัตร: ล็อกจนกว่าจะทำ Post-test (5 ข้อ) และแบบประเมินหลังเรียน แล้วสร้าง PDF ได้จริง
- ตรวจการบ้าน: กรอกค่าถูก/ผิดปนกัน ผลถูกต้อง, แบบทดสอบให้คะแนนตามคำตอบ, ฟอร์มลิงก์ปฏิเสธ `http:` และ `javascript:`, ชื่อผู้เรียนถูก escape (ทดสอบ XSS)
- สัญญากับหลังบ้าน: ตั้ง endpoint จำลองและดักจับ `fetch` ตรวจ payload ของ Lab/Workshop/ลิงก์/โน้ต/แบบทดสอบ/ตารางคะแนนตรงกับที่ `Code.gs` คาดหวัง
- **ยังไม่ได้ทำ:** ทดสอบกับ Apps Script จริง, ทดสอบกับพนักงานกลุ่มเล็ก, ทดสอบบนมือถือจริง (ดูเฉพาะมุมมองแคบในเบราว์เซอร์), ทดสอบหน้าจอ Gemini/Gemini Notebook จริงว่าตรงกับชื่อปุ่มในสื่อ
